## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização, animações, keyframes e variáveis CSS.
- **JavaScript (ES6+):** Manipulação do DOM e alternância das classes de animação.
